# 🤖 AURA — Adaptive Neural AI Work Assistant

AURA adalah asisten digital cerdas lintas platform (Android & Windows) dengan konsep avatar saraf adaptif yang terhubung langsung dengan Google Gemini dan Gmail untuk membantu otomasi pekerjaan, analisis pesan, dan penyusunan draf respons secara efisien.

---

## ✨ Fitur Utama

- **🧠 Adaptif & Cerdas**: Didukung oleh model AI Google Gemini untuk penalaran konteks dan analisis pesan.
- **✉️ Asisten Pekerjaan & Email**: Membantu merangkum email panjang, mendeteksi urgensi tugas, dan menyusun draf balasan profesional.
- **📱 Lintas Platform**: Berjalan lancar di perangkat **Android (APK)** dan komputer **Windows (EXE)**.
- **♿ Aksesibilitas Terpadu (WCAG)**: Mendukung *screen reader* (`liveRegion`), navigasi keyboard, dan rasio kontras visual yang ramah pengguna.
- **⚡ Cloud Build Otomatis**: Menghasilkan file instalasi APK dan EXE secara otomatis melalui GitHub Actions tanpa perlu menginstall SDK lokal.

---

## 🚀 Cara Mengunduh File Instalasi (APK / EXE)

1. Buka tab **Actions** di bagian atas repositori ini.
2. Klik proses build terbaru yang bertanda centang hijau (✅).
3. Gulir ke bagian paling bawah ke bagian **Artifacts**:
   - 📱 **`Aura_AI_Assistant_Android_APK`**: Unduh untuk di-install di ponsel Android.
   - 💻 **`Aura_AI_Assistant_Windows_EXE`**: Unduh (format ZIP) untuk dijalankan di Windows.

---

## 🔑 Penggunaan API Key

1. Buka aplikasi setelah di-install di Android atau Windows.
2. Masukkan kunci API Gemini gratis Anda yang bisa didapatkan di [Google AI Studio](https://aistudio.google.com/).
3. Masukkan tugas, draf email, atau instruksi kerja Anda ke dalam kolom teks, lalu klik **Kirim ke Aura AI**.
